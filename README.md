# Stay By My Side

An interactive "will you stay by my side?" program in Python (Tkinter), with a web version.

## Make it yours
- Open Stayspls.py and change THEIR_NAME and MY_NAME at the top.
- Add your own songs next to the script and set their file names and start times at the top.
- Change the messages in the PLEAS and NO_LABELS lists.

## Run it
    pip3 install pygame
    python3 Stayspls.py

## Web version
See the webapp folder:
    cd webapp
    pip3 install flask
    python3 app.py
Add ?to=TheirName&from=YourName to the link.

Songs are not included. Add your own mp3 files.
